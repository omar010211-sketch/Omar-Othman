# OMAR OTHMAN — Portfolio Package 2026

This package contains the responsive portfolio website and the matching portfolio PDF.

- `index.html` — responsive website with desktop/tablet/mobile layouts, mobile menu, smooth scrolling and image lightbox.
- `downloads/OMAR_OTHMAN_Portfolio.pdf` — redesigned portfolio PDF using the same dark/green visual system as the website, with dedicated campaign pages and large evidence images.
- `downloads/OMAR_OTHMAN_ATS_CV.pdf` — ATS-friendly CV.
- `downloads/OMAR_OTHMAN_ATS_CV.docx` — editable ATS CV.
- `assets/` — portfolio imagery.

Client reviews/testimonials are intentionally excluded from the website and portfolio.
